# What this patch does (plain language)

Yaiba for Game Boy only came out in Japan. This patch turns every bit of Japanese in it into English:
the story boxes between chapters, Onimaru's scenes, the power-up messages, the opening text, the
sword-select menu, the title, chapter cards, the health bar labels and the game-over screen.

Names come from the official English anime and manga (Yaiba Kurogane, Sayaka, Onimaru, Raijinken,
Fujinken, the Dragon Orb...). The Pyramid storyline this game tells was never animated, so a few
names (Emerald, the gem soldiers, some orbs) are our own choices.

What you'll notice: English text uses a narrow, book-like font so each box holds full sentences
instead of a few words, and the text still types out letter by letter like the original.
Orb icons are labelled with short letters (T = Thunder, W = Wind, St = Storm, Ov = Overlord,
Dk = Dark, Dr = Dragon) because the icons are tiny.
